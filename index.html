Expectations

  1. Defend the Alliance and vanquish the Horde.
    • Open world PvP is a lot of our end game.
  2. Stay immersed.
    • Voice chat will never be required of any member.
  3. Join thematic events to improve the Oaksworn renown.
    • Thematic vibes, not hardcore RPing.
  4. Keep it chill and casual.
    • No toxic tryhards, no obnoxious or offensive names/communication.
  5. Coordinate effectively.
    • Use in-game ping and install a few helpful addons (e.g., Overlord Forever, OneForAll Forever, BlitzFramesTargets).
